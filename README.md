# SimpleSite

A website served by a custom web server, developed as a university project for the Web Programming (PW) course. The repository is split into the website content (pages, styles and scripts) and the web server that serves it.

## Features

- **Website content** – pages, styles and client-side scripts kept separately in the `continut` folder
- **Custom web server** – a dedicated server in the `server_web` folder that serves the site to the browser
- **Clear separation** – front-end content and server code are independent, so either can be changed without touching the other
